# tron2_rl_deploy_python

LimX TRON2A 人形机器人的 RL 部署推理。通过 Python 加载 ONNX 策略，支持 SF（双足）和 WF（轮足）变体。

## 前提条件

- Python 3.8+

## 快速开始

```bash
git clone https://github.com/limxdynamics/tron2_rl_deploy_python.git
cd tron2_rl_deploy_python
pip install -r requirements.txt
python main.py
```
